# Недельный планер

Этот проект представляет собой интерактивный недельный планер, созданный на React.

## Особенности
- Визуализация расписания на каждый день недели.
- Возможность редактирования и удаления задач.
- Цветовая кодировка по категориям (Стартап, Контент/Клуб, IT-бот, Личное время).
- Адаптивный дизайн для мобильных устройств и десктопов.

## Как использовать
Откройте файл `index.html` в браузере или перейдите по ссылке на GitHub Pages.
